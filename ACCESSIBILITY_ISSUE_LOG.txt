Source finding: White text appeared over the original teal background (#168C8C), a contrast concern for normal-size text.

Element affected: Navigation and main content on all three pages.

3. Keyboard focus and current-page state
Element affected: Navigation links and main content.
Source finding: The original main landmark was not focusable, and the active page was indicated visually only.
WAVE reported: Confirm whether WAVE lists related alerts. Test keyboard focus manually as well.
User impact: Keyboard users need a visible focus indicator. Screen-reader users benefit from a programmatic current-page indicator.
Fix applied: Added a stronger focus outline and aria-current="page" to the active navigation link.
