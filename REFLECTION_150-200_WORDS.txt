I used ChatGPT to review my portfolio code and make accessibility improvements. First, I changed the navigation colors because white text on the original teal background raised a contrast concern. I used a darker teal to make the labels easier to read. Second, I added a “Skip to main content” link to each page. This helps keyboard users move past repeated navigation links and reach the page content faster. Third, I strengthened keyboard focus indicators and added an aria-current attribute to the active page link. These changes help keyboard and assistive-technology users understand where they are on the site.

This project taught me that accessibility affects how people interact with a website, not only how a website looks. A page needs readable text, clear navigation, and support for people who do not use a mouse. I also learned that automated tools and manual testing serve different purposes.
